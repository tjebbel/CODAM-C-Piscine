Pointers

Functions receive copies from their arguments. 
If you want to change a variable of the called function, an address is needed - a pointer in computer terms.
Pointers are read from right to left (int **p) = "p is a pointer to a pointer to an int"
There are two types of pointers 
1. declaration => (int *a) : the star belongs to the type
2. expression => *a = *b : go to address and use value of this pointer

& = address or '&x' "write down address of the house"
* = touch or '*p' "look inside the house on the address"
